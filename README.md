# WhiteEye

The current website source is in **[website/](website/)**, refreshed from the
active local project on 25 October 2026. It includes the conversation interface,
personas, reading room, course content, appearance options, local-server support,
Workers build and tests.

- [Website setup and architecture](website/README.md)
- [Source export manifest](website-export.json)
- [Download the current source archive](Whiteeye_Therapy_Website.zip)

The source export includes the current uncommitted local code/documentation
updates. Credentials, generated private source indexes, learner databases,
browser history, build output and design-tool state are excluded. The private
indexes remain required inputs for the source-grounded application; see
[private input requirements](website/private/README.md) before building.

The earlier `whiteeye_therapy/` Next.js application, original source/profile files
and `Uploads/` remain available as historical material. The current implementation
and its setup instructions are under `website/`.
